Bestehende Bibliothekssynchronisationen können

  • ausgesetzt (d.h. pausiert)
  • manuell angestoßen
  • getrennt und
  • neu synchronisiert

werden.

Alle diese Optionen erreichen Sie über das Kontextmenü mit einem rechten Mausklick auf eine Bibliothek.

Sollte eine Synchronisation mal nicht mehr funktionieren, dann prüfen Sie, ob Manuell synchronisieren die Synchronisation wieder in Gang setzt. Bringt dies nichts, dann können Sie mit Neu synchronisieren die Synchronisationsbeziehung auf Client und Server beenden und die Synchronisation neu einrichten. In diesem Rahmen werden Metadaten auf dem Client gelöscht, wodurch potentielle Probleme beseitigt werden. Alternativ können Sie eine Synchronisation mit Synchronisation trennen auch beenden, um sie im Anschluss daran wieder manuell einzurichten.
