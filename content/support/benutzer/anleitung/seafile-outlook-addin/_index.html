Das Seafile Add-in für Outlook (kurz Add-in) ist eine Erweiterung für das weit verbreitete Programm von Microsoft zum Abrufen und Versenden von E-Mails. Das Add-in erlaubt den Zugriff auf Funktionen von Seafile direkt aus Outlook heraus. So können Freigabe-Links für Ordner und Dateien direkt in Outlook erstellt und in E-Mails eingefügt werden. Der Wechsel in das Seafile Webinterface ist dadurch nicht mehr notwendig. Das Add-in ermöglicht außerdem den Direktupload von Dateianhängen und E-Mails in Seafile Bibliotheken und Ordner.

Das Add-in muss einmalig eingerichtet werden. Über eine separate Registerkarte Seafile im Menüband stehen seine Funktionen zur Verfügung. Die drei Schaltflächen Mein Seafile, Einstellungen und Info werden im Menüband immer angezeigt.

Die Schaltfläche Mein Seafile ruft das Seafile Webinterface in einem Browser-Fenster. Der Login an Seahub erfolgt automatisch. Einstellungen ruft den Login-Dialog auf. Das Add-in unterstützt 2-Faktor Authentifizierung sowie Single Sign-On.

Die Schalftflächen Upload und Teilen, über die sich die Funktionen des Add-ins ansteuern lassen, werden nur dann eingeblendet, wenn eine E-Mail in einem separaten Fenster bzw. im Bearbeitungsmodus geöffnet ist.

Das Seafile Add-in für Outlook ist kompatibel mit gängigen 32-Bit Versionen von Outlook für Windows. Das Add-in funktioniert nicht mit 64-Bit Versionen von Outlook für Windows. Outlook für Mac wird ebenfalls nicht unterstützt.

Das Add-in kann von der Downloadseite kostenfrei heruntergeladen und mit Seafile Server Enterprise Edition sowie mit Seafile Server Community Edition verwendet werden.
