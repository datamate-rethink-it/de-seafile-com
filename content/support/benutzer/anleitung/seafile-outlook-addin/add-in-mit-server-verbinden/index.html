Nach der Installation des Add-ins ist ein Neustart von Outlook notwendig, um das Add-in zu laden. Nach dem Neustart wird im Menüband eine Registerkarte Seafile angezeigt. Klicken Sie in diesem auf Einstellungen, um den Dialog zum Anmelden aufzurufen.

Sie müssen nun die Adresse Ihres Seafile Servers und Ihre Benutzerkontodaten eingeben. Bei Server geben Sie die Serveradresse Ihres Seafile Servers ein. Das ist die Adresse, unter der Sie auch Seahub im Browser aufrufen. Diese Adresse muss mit vorangehendem https:// eingegeben werden (z.B. https://demo.seafile.com. Benutzername und Passwort sind identisch mit den Zugangsdaten, die Sie für die Anmeldung an Seahub verwenden. Klick Sie dann auf Login. Eine Meldung bestätigt die erfolgreiche Verbindung zum Server. Wenn Sie 2-Faktor Authentifizierung aktiviert haben, dann müssen Sie in einem separaten Fenster noch den zweiten Faktor eingeben.

Erfolgt bei Ihnen die Anmeldung per Single Sign-On (SSO), dann geben Sie nur die Adresse Ihres Seafile Servers ein und lassen die Felder für Benutzername und Passwort leer. Klicken Sie dann auf SSO.

Die Anmeldung per SSO erfordert eine serverseitige Konfiguration.

Das Seafile Add-in für Outlook unterstützt nur eine Serververbindung, d.h. Sie können über das Add-in nicht auf mehrere Seafile Benutzerkonten zugreifen. Durch erneuten Klick auf Einstellungen sehen Sie, mit welchem Benutzerkonto und welchem Seafile Server das Add-in verbunden ist. Um zwischen Seafile Konten zu wechseln, müssen Sie die Serververbindung des Add-ins zurücksetzen und sich erneut anmelden. Dies können Sie ebenfalls über den Anmelden-Dialog machen, den Sie über Einstellungen aufrufen können.
