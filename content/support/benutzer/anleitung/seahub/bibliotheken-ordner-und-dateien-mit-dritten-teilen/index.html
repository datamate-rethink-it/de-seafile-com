Freigaben (siehe Bibliotheken und Ordner an andere Benutzer freigeben) können nur für in Seafile angelegte Benutzer und Gruppen erfolgen. Wenn Sie Daten mit Dritten teilen oder Dritten den Upload von Dateien erlauben wollen, dann können Sie dies über einen Public Link tun.

Ein Download-Link erlaubt es einer dritten Person, Dateien durch Aufruf einer URL herunterzuladen. Über einen Upload-Link kann eine Dritte Person Dateien in eine Seafile Bibliothek bzw. einen Ordner hochladen, ohne sich anzumelden.

Download-Links

Zur Erstellung eines Download-Links bewegen Sie den Mauszeiger in die Zeile der Bibliothek, des Ordners bzw. der Datei, für die Sie einen Link erstellen wollen, und klicken Sie dann auf das Freigabe-Icon. Im sich öffnenden Dialog wählen Sie nun Link freigeben. Mit Klick auf Erstellen wird der Link erstellt und angezeigt. Den Link können Sie dem Empfänger dann per E-Mail oder auf anderem Wege mitteilen.

Download-Links können mit einem Passwort geschützt, mit einer Befristung versehen und nur zur online Anzeige freigegeben werden. Aktivieren Sie bei Bedarf die entsprechenden Kästchen.

Upload-Links

Upload-Links lassen sich für Bibliotheken und Ordner erstellen. Bewegen Sie den Mauszeiger in die Zeile der Bibliothek bzw. des Ordners, in den Dritte Dateien und Ordner hochladen können sollen, und klicken Sie dann auf das Freigabe-Icon. Im sich öffnenden Dialog wählen Sie nun Upload-Link. Mit Klick auf Erstellen wird der Link erstellt und angezeigt. Den Link können Sie dem Empfänger dann per E-Mail oder auf anderem Wege mitteilen.

Upload-Links können mit einem Passwort versehen werden.
