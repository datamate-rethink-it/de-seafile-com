Jede Bibliotheken hat immer einen Besitzer. In der Seafile Community Edition sind Besitzer immer auch Benutzer. In der Professional Edition können auch Gruppen Bibliotheken besitzen. Durch eine Übertragung einer Bibliothek lässt sich der Besitzer wechseln.

Zum Übertragen einer Bibliothek klicken Sie auf das Icon für die erweiterten Optionen. Die Icons tauchen auf, sobald Sie den Mauszeiger in die Zeile einer Bibliothek ziehen. Wählen Sie aus den erweiterten Optionen Übertragen.

In dem sich öffnenden Dialog geben Sie nun den Benutzernamen des zukünftigen Eigentümers der Bibliothek ein. Wenn die Auto-Complete Funktion aktiviert ist, dann werden Ihnen bereits bei der Eingabe eines Buchstaben mögliche Kandidaten angezeigt. Wählen Sie den Benutzer aus. Wenn Auto-Complete deaktiviert ist, dann geben Sie den vollständigen Namen ein.

Die Übertragung einer Bibliothek lässt sich nur durch den neuen Besitzer rückgängig machen, indem er die Bibliothek wieder an Sie zurücküberträgt.

Um eine Bibliothek von einem Benutzer auf einen Bereich zu übertragen, klicken Sie im Dialog auf Übertragen auf Bereich. Geben Sie dann den Namen des Bereichs ein, an den die Bibliothek übertragen werden soll, und bestätigen Sie die Übertragung mit Absenden.

Die Übertragung einer Bibliothek auf einen Bereich lässt sich nicht rückgängig machen.
