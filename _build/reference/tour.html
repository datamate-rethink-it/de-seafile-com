Seafile TourLernen Sie Seafile kennen

Seafiles Zielsetzung ist simpel: Die gemeinsame Bearbeitung von Dateien so einfach wie möglich. Sehen Sie selbst wie Seafile das macht.

Jetzt Seafile ausprobieren Seafile Handout

File Cloud

Seafile macht Ihre Dateien universell verfügbar. Auf dem Laptop, dem Smartphone, unterwegs, daheim, im Büro – Sie haben Ihre Daten immer und überall dabei.

Internal Sharing

Mit Seafile teilen Sie Ihre Daten mühelos mit anderen Benutzern. Sie bestimmen mit wem und unter welchen Bedingungen Sie Ihre Dateien zur Verfügung stellen.

Synchronisation

Seafile synchronisiert die Bibliotheken auf dem Seafile Server mit Ihrem Arbeitsplatzrechner. So haben Sie auch offline Zugriff auf alle Ihre Dateien. Änderungen werden an andere Geräte übermittelt – automatisch und zuverlässig.

Online File Editing

Bearbeiten Sie Office Dokumente gemeinsam und gleichzeitig. Sie sehen unmittelbar die Änderungen der Kollegen und können so der Kreativität freien Lauf lassen.

Public Sharing

Seafile macht die organisationsübergreifende Zusammenarbeit an Dateien und Dokumenten ganz einfach. Public Links, Co-Bearbeitung und Gastfunktion sorgen dafür.

File Locking

Machen Sie Versionskonflikte durch die gleichzeitige Bearbeitung von Dateien ein Ding der Vergangenheit. Seafile sperrt Office Dokumente in Bearbeitung und kommuniziert die Sperrung an andere Benutzer.

Full Text Search

Mittels Volltextsuche und den erweiterten Suchoptionen finden Sie jede Dateien im Nullkommanix.

Wiki

Bauen Sie strukturiert Wissen auf, machen Sie es zentral verfügbar und kommunizieren Sie effektiv im Team. Die Seafile Wikis unterstützen Sie dabei.

File Versioning

Stellen Sie frühere Versionsstände einzelner Dateien oder ganzer Bibliotheken per Knopfdruck wieder her und ersparen Sie sich den Rückgriff auf das Backup.

AD/LDAP

Seafile macht die Benutzerverwaltung ganz einfach – mit der Integration von Seafiles Benutzerdatenbank mit Ihrem AD/LDAP-Verzeichnis.

Admin Delegation

Erlauben Sie die Eigenverwaltung von Seafile durch organisatorische Einheiten – unter durch den Administrator gesetzten Rahmenbedingungen

Multi Tenancy

Ein System, mehrere Tenants mit strikt separierten Benutzerkreisen. Nutzen Sie Seafile in Ihrem Rechenzentrum, um Ihren Kunden Sync & Share unter Ihrem Namen anzubieten.

API

Seafile ganz flexibel: Die REST API sorgt für maximale Möglichkeiten bei Anpassung von Seafile und der Integration seiner Funktionen.

Storage Backends

Ökonomische wie technische Gründe sprechen für die Kombination unterschiedlicher Speichermedien. Seafile macht dies ganz einfach.

Cluster

Hochverfügbarkeit und optimale Performance erreichen Sie mit einem Seafile Cluster. In Kombination mit einem verteilten Speichersystem ist Downtime ein Ding der Vergangenheit.
