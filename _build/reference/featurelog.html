Seafile Server FeaturelogWelche Funktion kam wann?

Das Seafile Entwicklerteam arbeitet unermüdlich, um Seafile noch besser zu machen. Das Featurelog stellt die wichtigsten Entwicklungsschritte des Seafile Server Professional Edition seit Version 5 aus Funktionssicht dar. Das vollständige englischsprachige Change Log für Professional und Community Edition sowie alle Clients finden Sie im Seafile Manual.

Version 7.x
Version Datum Feature Beschreibung
7.0.5 16. Juli 2019 Befristung von Upload-Links Upload-Links verfallen automatisch nach Ablauf einer frei wählbaren Frist.
7.0.2 17. Mai 2019 Bibliothekstransfer von Benutzer zu Bereich Bibliotheken lassen sich von einem Benutzer auf einen Bereich übertragen, dessen Mitglied der Benutzer ist.
Individuelle Salts für verschlüsselte Bibliotheken Individuellen Salts bieten einen besseren Schutz gegen Brute-Force-Angriffe.
7.0.1 18. April 2019 Datei Tags In Tags lassen sich Meta-Informationen für Dateien erfassen (z.B. Bearbeitungsstatus, Priorität, zuständige Person).
Spaltenansicht Eine zusätzliche Spalte in Seahub stellt die Baumstruktur einer Bibliothek dar und erlaubt die Dateiverwaltung wie in einem Datei Manager.
Veröffentlichte Bibliotheken / Wikis Bibliotheken lassen sich unter einer individuellen URL veröffentlichen und sind so für jeden zugänglich.
Freigabeberechtigungen ‚Online Lesen + Schreiben‘ und ‚Online Nur Lesen‘ Die Freigaben erlauben Lese + Schreib- bzw. nur-Lese-Zugriff über Seahub, aber keinen Download oder die Synchronisation.
Echtzeitsuche Die Suche stellt die Suchergebnisse in Echtzeit bei Eingabe des Suchbegriffs dar.
E-Mail Benachrichtigung für Aktivitäten Nutzer erhalten automatisch in der gewählten Frequenz den Aktivitätenbericht per E-Mail zugesendet.
Version 6.x
Version Datum Feature Beschreibung
6.3.8 11. Dezember 2018 Dateivorschau Für AI- und PSD-Dateien bietet Seahub eine Vorschau-Funktion.
WebDAV-Anmeldung mit Shibboleth WebDAV-Authentifizierung ist auch über Shibboleth möglich.
WebDAV-Anmeldung mit Kontakt-E-Mail-Adresse Neben der Anmeldung mit der E-Mail-Adresse ist auch die WebDAV-Authentifizierung über den E-Mail-Kontakt möglich.
6.3.7 16. Oktober 2018 Traffic-Statistiken Erweitertes Statistikmodul für benutzerbasierte Trafficauswertungen.
6.3.5 19. September 2018 Traffic-Statistiken Statistikmodul ermittelt den täglichen Traffic via Web, Links und Synchronisation.
Berechtigung für Download-Link ‚Bearbeiten online und herunterladen‘ Über diesen Link Typ kann ein Dokument durch Externe bearbeitet und heruntergeladen werden.
6.3.3 15. August 2018 Seahub-Anmeldung mit Kontakt-E-Mail-Adresse Neben der Anmeldung mit der E-Mail-Adresse ist auch die Seahub-Authentifizierung über den E-Mail-Kontakt möglich.
6.3.2 30. Juli 2018 Neuer Gruppentyp ‚Bereich‘ Bereiche können Bibliotheken besitzen, ein Bereichsadministrator verwaltet Mitglieder, Unterbereiche und Datenstrukturen.
Robuste Public Links Public Links in Seafile sind immun gegen Dateitransaktionen (z.B. Namensänderung der Datei oder Ordner).
Internal Links Neuer Linktyp für interne Verweise auf Dateien/Ordner. Der Aufruf des Links erfordert mindestens Lese-Berechtigung für den Ordner/Datei.
Multiple Storage Backends Der Seafile Server unterstützt mehrere lokale Speicherpfade.
WYSIWYG-Markdown Editor Der neue Editor vereinfacht die Bearbeitung von MD-Dateien.
API-Calls für Multi Tenancy Organisationen ‚Get‘, ‚Put‘ und ‚Delete‘ Mit API-Aufrufen können Organisationsinformationen abgerufen und aktualisiert sowie Organisationen gelöscht werden.
6.2.2 12. Dezember 2017 Freigabeberechtigung für Bibliothek ‚Administration‘ Mit der Freigabeberechtigung ‚Administration‘ können neben Lese- und Schreibaktionen auch weitere Freigaben erteilt werden.
OAuth Unterstützung Authentifizierung mittels Oauth ist über andere Authentifizierungsdienste möglich.
Snapshot Labels Snapshots von Bibliotheken können mit einer Bezeichnung für die spätere, einfachere Auffindbarkeit versehen werden.
Statistik Modul Seahub bietet Auswertung der täglichen aktiven Benutzer, Dateioperationen und der Speicherplatzbelegung.
6.1.1 19. Juni 2017 Integration von OnlyOffice Office Dokumente können mit OnlyOffice aus Seahub heraus direkt im Browser bearbeitet werden.
Berechtigung für Download-Link ‚Online Vorschau‘ Über Online Vorschau-Link kann ein Dokument angeschaut, aber nicht heruntergeladen werden.
6.0.2 20. Oktober 2016 Rollenbasierte Berechtigungsvergabe Individuelle Anpassungen der vordefinierten und die Anlage neuer Rollen vereinfachen die Berechtigungsverwaltung.
Gasteinladung Externe können als Gäste eingeladen werden und haben begrenzten Zugriff auf geteilte Bibliotheken und Ordner.
Integration von Collabora Online Office Dokumente können mit Collabora aus Seahub heraus direkt im Browser bearbeitet werden.
2-Faktor Authentifizierung Ein weiterer Authentifizierungsfaktor neben Benutzername & Passwort ist für den Login erforderlich.
Fernlöschung Synchronisierte Daten auf einem Client lassen sich ohne Zugriff auf das Gerät löschen (z.B. bei Geräteverlust).
Dateikommentare Benutzer können in Seahub Dateien Kommentare hinzufügen.
Responsive Webinterface Das Design des Webinterfaces Seahub reagiert auf das benutzte Endgerät.
Support für Seafile Drive Client Der Seafile Server unterstützt den Seafile Drive Client.
Terms and Conditions Die Nutzung von Seafile ist durch neuen Benutzer erst nach Annahme der Nutzungsbedingungen möglich.
Version 5.x
Version Datum Feature Beschreibung
5.1.4 17. Mai 2016 Unterstützung mehrerer AD/LDAP-Server Seafile unterstützt die Authentifizierung über mehrere Active Directories bzw. LDAP-Verzeichnisse.
Mehrdateien-Download Über Seahub können mehrere Dateien gleichzeitig herunter geladen werden.
5.1.1 8. April 2016 File Locking Office Dateien werden während der Bearbeitung durch einen Benutzer automatisch für die Bearbeitung durch andere Nutzer gesperrt.
Multi Institutions Seafile führt Einrichtungen ein. Mit Einrichtungen lassen sich organisatorische Strukturen abbilden und administrative Aufgaben delegieren.
Real-Time Backup Seafile unterstützt Echtzeitreplikation von Datenspeicher und Datenbank eines Produktivservers auf einen Backupserver.
5.0.4 20. Januar 2016 HTTPS Support für S3 SSL-verschlüsselte Verbindungen zu einem S3-Backend sind möglich.
5.0.2 4. Dezember 2015 Exportfunktion Audit Log und Benutzer- und Gruppeninformationen können in Excel exportiert werden.
Web-basierte Server-Konfiguration Seafile Server ist teilweise über Seahub konfigurierbar.
Conf-Ordner Alle Konfigurationsdateien liegen im Conf-Ordner.
