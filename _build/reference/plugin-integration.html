Seamate

Nach dem Austauch des Seafile Logos durch das eigene soll Seafile auch farblich an das Corporate Design angepasst werden? Seamate macht die Farbänderung des Seafile Webinterfaces Seahub zum Kinderspiel! Weder Programmierkenntnisse noch Kommandozeilenakrobatik sind notwendig, um das Seafile Orange in die individuelle Wunschfarbe zu ändern.

Seamate ist ein webbasierter CSS-Generator von der Mainzer datamate GmbH & Co. KG. Einfach auf der Seamate Webseite die Wunschfarbe auswählen, den von Seamate erzeugten CSS-Code kopieren und im Webinterface als Custom CSS einfügen – schon erstrahlt das Webinterface in der individuellen Farbe. Seamate arbeitet ohne Änderungen am Seafile Server oder der Anwendungslogik von Seahub und vermeidet so mögliche Konflikte.

Collabora Online

Mit Collabora Online bearbeiten Sie Office Dokumente direkt im Browser aus dem Seafile Webinterface heraus. Die Editoren für Dokumente, Tabellen und Präsentationen erlauben die Bearbeitung von Dateien im OpenDocument-Dateiformat (ODT, ODS, ODP) und durch Konvertierung auch solche im OOXML-Format (DOCX, XLSX, PPTX). Auch die gleichzeitige Bearbeitung von Dokumenten mit mehreren Personen ist möglich. So unterstützt Collabora Online die effiziente Zusammenarbeit im Team.

Collabora Online basiert auf der bekannten Office Suite LibreOffice und wird von Collabora Productivity entwickelt. Collabora Productivity bietet den Dokumentenserver in zwei Editionen an: Collabora Online ist für eine unbeschränkte Anzahl an Benutzern geeignet und bietee Business Support. Die Collabora Online Development Edition (CODE) ist die Entwicklungsversion, die für kleinere Teams geeignet ist.

ONLYOFFICE Online Editoren

Die Online Editoren von ONLYOFFICE integrieren vielseitige Bearbeitungsfunktionen für Dokumente, Tabellen und Präsentationen in das Seafile Webinterface Seahub. Mit nur einem Klick können Office Dokumente direkt im Browserfenster alleine oder von mehreren Leuten gleichzeitig bearbeitet werden. Die Editoren von ONLYOFFICE bieten höchste Kompatibilität mit den Microsoft Office Formaten DOCX, XLSX und PPTX.

Die ONLYOFFICE Online Editoren werden von der lettischen Ascensio System SIA entwickelt. Es gibt mehrere Editionen: Die Community Edition (CE) ist Open Source und unterstützt max. 20 gleichzeitige Serververbindungen. Die Enterprise Edition (EE) gibt es ab 1.020€. Sie bietet 50 und mehr gleichzeitige Verbindungen und einen erweiteten Funktionsumfang.

Microsoft Office Online Server

Microsoft Office setzt seit Jahrzehnten als Office Suite Standards auf Desktop Rechner. Der Microsoft Office Online Server (OOS) bringt die leistungsfähigen Editoren aus dem Haus Microsoft auf den eigenen Server und stellt sie anderen Cloud Anwendungen zur Verfügung. Word, Excel und PowerPoint Dokumente lassen sich direkt im Seafile Webinterface öffnen und bearbeiten. Allein oder gemeinsam arbeitet man bequem in den browserbasierten Online Editoren von Microsoft (ehemals Web Apps genannt), deren Benutzeroberfläche unmittelbar an die Desktop Editoren erinnert.

Microsoft OOS ist Bestandteil von Microsoft Office 365 Pro Plus und steht auch über das Volume Licensing Center Office Benutzern mit Software Assurance zur Verfügung. Es kann nicht als eigenständiges Produkt erworben werden. MS OOS muss auf einem separaten Windows Server 2012 R2 oder Windows Server 2016 installiert werden.

Seafile Plugin für Kopano

Das Seafile Plugin für Kopano bindet Seafile als File Backend in die Groupware Kopano ein und macht so Seafiles File Sharing und File Collaboration Fähigkeiten direkt in Kopanos Webinterface verfügbar. Nutzer können direkt im Kopano Browserfenster auf ihre persönlichen Dateien zugreifen und mit anderen teilen. Seafile Nutzer können mit Kopano die Sync & Share Funktionen von Seafile um E-Mail, Terminkalender, Adressbuch und Chat Funktionalitäten ergänzen.

Das Seafile Plugin für Kopano wurde von der datamate GmbH & Co. KG entwickelt und wird von dem Mainzer Unternehmen auch betreut. Das Plugin, das unter einer open-source Lizenz veröffentlicht wurde, ist über GitHub verfügbar.

Seafile Outlook Add-In

Mit dem Seafile Add-In für Microsoft Outlook lassen sich ganz einfach Dateien austauschen, ohne auch nur einen E-Mail-Anhang zu versenden. Probleme beim Versand großer Anhänge sind damit Vergangenheit. Upload- und Download-Links können direkt in Outlook ohne Wechsel zu Seafile erzeugt und in E-Mails eingefügt werden.

Sharing Links lassen sich ganz einfach über ein separates Fenster in Outlook E-Mails einfügen. Durch Passwortschutz, Verfallsdaten und individuelle Zugriffsrechte wird der Austausch von Dateien nicht nur bequemer, sondern auch sicherer. Dank Outlook Add-In können E-Mails und E-Mail-Anhänge auch direkt in Seafile gespeichert werden.

Seafile Zimlet

Das Seafile Plugin für Zimbra (Seafile Zimlet) integriert Seafiles leistungsfähige Funktionen für den Dateiaustausch und die Dateizusammenarbeit in die Collaboration-Lösung Zimbra. Über einen separaten Tab in der Weboberfläche von Zimbra erhalten die Nutzer direkten Zugriff auf ihre in Seafile gespeicherten Dateien. Der Austausch von Dateien wird dadurch noch leichter. Außerdem bietet das Zimlet eine weitgehende Integration mit Zimbras Mail Funktionen. Seafile in Kombination mit Zimbra ist die sichere, preisgünstige und selbstgehostete Alternative zu Microsofts Office 365 und der G Suite von Google.

Das Seafile Zimlet wurde von der datamate GmbH & Co. KG in Zusammenarbeit mit der ZETA Alliance entwickelt. Der Code ist direkt auf GitHub verfügbar und kann als open-source Software uneingeschränkt kostenlos genutzt werden.
